# Contributing Guidelines

Thank you for your interest in contributing to this project!
This repository is licensed under the MIT License, which means contributions are welcome and encouraged.

---
## How to Contribute

### 1. Fork & Clone
- Fork the repository to your GitHub account.
- Clone your fork locally:
  git clone https://github.com/<your-username>/<repo-name>.git

### 2. Create a Branch
Use a descriptive branch name:
  fix-watcher-refresh

### 3. Make Your Changes
- Keep code clean, readable, and consistent with existing style.
- Include comments for complex logic.
- Test your changes before committing.

### 4. Commit & Push
Write clear commit messages:
  "Fix watcher refresh after command removal"

### 5. Open a Pull Request
- Open a PR against the main branch.
- Describe what you changed and why.
- Reference related issues (e.g., Closes #12).

---
## Testing
Before submitting a PR:
- Run the project and ensure no errors appear in the Debug Terminal.
- Verify watchers, commands, and panels behave correctly.
- Confirm font scaling and viewport layout remain consistent.

---
## Reporting Issues
If you find a bug or want a feature:
1. Search existing issues first.
2. If none exist, open a new issue using the template.
3. Include:
   - Steps to reproduce
   - Expected vs actual behavior
   - Environment details (OS, GPU, Godot version)
